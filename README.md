# Steal a Chami — expanded browser prototype

Unofficial, fictional fan game. Includes all 174 entries listed in the public Chaminade High School faculty **and staff** directory as of October 2026 (not all are teachers). Names and departments are public directory information; rarities are fictional and do not evaluate real people.

## Play
Open `index.html` in a browser. Local player names and a local leaderboard are supported. Demo admin unlock code: `FLYERS-DEMO` (not secure; demo only).

## GitHub Pages
Upload `index.html`, `teachers.js`, `upgrades.js` to the repository root. Enable Pages under Settings → Pages → Deploy from branch → main / root.

## Important limitations
The campus is a CSS isometric preview, **not** a third-person 3D world. Rivals are simulated, not real multiplayer. Accounts and leaderboard are **local to each browser**, not networked, and the demo admin code is visible in source. The admin panel shows event controls but only Flyer Frenzy connects to the existing event system. Never enter a real password. For real accounts, global leaderboards, multiplayer and server-authorized admin events, a hosted backend and authentication service are necessary.
